# Claude Blocked Exporter

Набор из трёх готовых JavaScript-скриптов для экстренного бэкапа всех диалогов, кода и артефактов из десктопного приложения **Claude Desktop** (Windows) или веб-версии, если аккаунт переведён в режим ожидания подтверждения (**Verification Portal**) или ограничен, а стандартная кнопка **Export data** в настройках не срабатывает.

### Что умеют скрипты
* **Работают без ручных правок:** автоматически определяют ID вашей организации из активной сессии.
* **Забирают всё за весь период:** выгружают абсолютно все чаты с параметром `render_all_tools=true`, сохраняя код из артефактов и вызовов инструментов.
* **Очищают и нарезают в Markdown:** вырезают технические заглушки вида `This block is not supported on your current device yet` и сохраняют каждый диалог в отдельный читаемый `.md` файл, готовый к загрузке в Qwen, DeepSeek или любую другую нейросеть.

## Шаг 1. Активируем режим разработчика и открываем консоль

### В десктопном приложении Claude (Windows)
В актуальных сборках панель разработчика скрыта. Включить её можно через конфигурационный файл:
1. Полностью закройте приложение Claude через Диспетчер задач (`Ctrl + Shift + Esc` -> выделить процессы **Claude** -> **Снять задачу**).
2. Нажмите `Win + R`, вставьте путь `%LOCALAPPDATA%\Packages` и нажмите **Enter**.
3. Откройте папку, в названии которой есть слово `Claude` (например, `Claude_pzs8sxrjxfjjc`), и перейдите внутри по пути: `LocalCache\Roaming\Claude`.
4. Создайте файл `developer_settings.json` (убедитесь, что у файла нет скрытого расширения `.txt`), вставьте внутрь следующий код и сохраните (`Ctrl + S`):

```json
{
  "allowDevTools": true
}
```

5. Запустите Claude заново, нажмите клавишу `Alt` -> **Developer** -> **Show Dev Tools** (или сочетание `Ctrl + Alt + I`) и перейдите на вкладку **Console**.

*(Если вы пользуетесь браузерной версией `claude.ai`, просто нажмите `F12` и откройте вкладку **Console**)*.

## Шаг 2. Разблокируем вставку кода в консоль

1. Кликните мышкой в нижнюю строку консоли рядом с синей стрелочкой `>`.
2. Введите вручную с клавиатуры `allow pasting` и нажмите **Enter**.
3. Если появится жёлтое предупреждение безопасности — введите `allow pasting` ещё раз и снова нажмите **Enter**.

---

## Шаг 3. Запускаем скрипты по очереди

1. **Выгрузка полного архива в JSON (`1_export_conversations.js`)**
   Скопируйте код из первого файла, вставьте в консоль (`Ctrl + V`) и нажмите **Enter**. Дождитесь надписи `Готово!` — в папку **Загрузки** сохранится файл `claude_full_tools.json`.
2. **Проверка дат и количества сообщений (`2_check_stats.js`)**
   Вставьте второй скрипт в консоль, нажмите **Enter** и выберите скачанный `claude_full_tools.json`. Консоль выведет сводную таблицу с названиями всех бесед, датами создания и числом сообщений.
3. **Очистка и нарезка на отдельные Markdown-файлы (`3_split_to_markdown.js`)**
   Запустите третий скрипт и выберите `claude_full_tools.json`. Скрипт удалит системные заглушки и сохранит каждый диалог в отдельный файл формата `1_Название_чата.md`. *(При запросе браузера или приложения на скачивание нескольких файлов нажмите **Разрешить**)*.

---

## Как вернуть приложение в исходное состояние

После выгрузки всех файлов закройте панель DevTools, удалите файл `developer_settings.json` из папки `LocalCache\Roaming\Claude` (или замените `true` на `false`) и перезапустите приложение через Диспетчер задач.
